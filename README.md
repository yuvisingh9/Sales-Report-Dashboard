# Sales Report Dashboard

## Project Overview
This project presents a Sales Report Dashboard created using Google Sheets to analyze sales performance and organize sales data into a clear, easy-to-understand report.

## Key Features
- **Total Sales:** Calculates overall sales revenue.
- **Total Orders:** Counts sales records.
- **Total Profit:** Estimates profit using sales quantity, unit cost, unit price, and discount.
- **Daily Sales Analysis:** Summarizes sales by date.
- **Weekly Sales Analysis:** Groups sales by week.
- **Monthly Sales Analysis:** Compares sales across months.
- **Currency Formatting:** Displays sales figures in Indian Rupees (₹).

## Dataset
The dataset includes:
- Product ID
- Sale Date
- Sales Representative
- Region
- Sales Amount
- Quantity Sold
- Product Category
- Unit Cost
- Unit Price
- Customer Type
- Discount
- Payment Method
- Sales Channel
- Region and Sales Representative
